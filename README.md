# PageDock

基于 Electron 和 Chromium 的独立 macOS 网页应用。通过名称和网址保存常用页面，在独立窗口中访问本地服务、局域网地址或普通网站。

## 功能

- 保存、搜索、切换、编辑和移除页面。
- 打开网页后默认收起侧边栏，通过顶部按钮展开；没有打开页面时自动展开。
- Zen Mode 隐藏侧边栏、地址栏、窗口控制按钮和常驻目录，只保留顶部的窄拖动区域与退出按钮。
- 后退、前进、刷新及网页弹窗。
- 自动、浅色和深色外观，默认跟随系统；App 外观与网页自身配色分开。
- 在本机保留网页登录状态、页面列表和偏好设置。
- 内置可独立开关的 Vimium Lite 与 TOC 目录，默认关闭。

## 使用

打开 App，点击「新增页面」，填写名称和网址，例如 `localhost:3000` 或 `https://example.com`。

本地服务仍需单独启动。PageDock 使用自己的登录空间，首次访问需要重新登录，不读取 Chrome 的用户配置。

侧边栏底部可以切换外观和插件。TOC 根据主页面的标题生成目录，支持点击跳转和动态更新；不读取跨域内嵌页面的标题。

网页打开后，点击工具栏的「进入 Zen Mode」，或使用 `⌘⇧Enter`、菜单「专注 → Zen Mode」切换。顶部「退出 Zen」按钮始终可用；退出后恢复侧边栏和目录状态，切换过程不刷新网页。Zen Mode 默认关闭，仅作用于当前窗口，导航和刷新时保持开启，返回概览、打开页面编辑框或重新启动后恢复普通模式。全屏仍可通过 macOS 的全屏菜单单独切换。

### Vimium Lite

这是内置的精简键盘导航功能，不是完整的 Vimium 浏览器扩展。先开启插件，再点击网页区域使用：

| 快捷键 | 功能 |
| --- | --- |
| `j` / `k` | 向下 / 向上滚动 |
| `h` / `l` | 向左 / 向右滚动 |
| `d` / `u` | 向下 / 向上半页 |
| `gg` / `G` | 到顶部 / 底部 |
| `f` / `F` | 显示链接提示 / 在新窗口打开链接 |
| `H` / `L` | 后退 / 前进 |
| `r` | 刷新 |
| `?` / `Esc` | 查看帮助 / 关闭提示 |

输入框、可编辑文本区域和输入法组合输入期间不拦截这些按键。

## 开发与测试

需要 macOS、Node.js 22.12 或更高版本及 npm。构建还需要 Xcode 或 Command Line Tools 提供的 Swift 和 macOS 开发工具。

```sh
npm ci
npm start
```

```sh
npm test
npm run test:app -- ./tmp/test-results
```

应用测试仅访问 example.com、Wikipedia 等无需登录的常用公开页面，使用独立的临时数据目录，退出后清理测试数据；截图保存在指定输出目录。测试约束见 [项目规范](AGENTS.md)。

## 构建

当前构建脚本只支持在 Apple Silicon Mac 上生成 macOS arm64 应用。

```sh
npm run build -- ./tmp/dist
```

产物位于 `tmp/dist/PageDock-darwin-arm64/PageDock.app`，可拖入「应用程序」目录。构建使用本地签名，不包含 Apple Developer ID 签名或公证。输出目录中已有同名产物时，构建会停止，需选择新的输出目录。

## 自动构建与 Release

推送到 `main` 后，GitHub Actions 会执行单元测试、构建应用、运行隔离的公开页面测试，并创建包含 macOS arm64 ZIP 和 `SHA256SUMS` 的 Release。可从仓库的 [Releases 页面](https://github.com/a1exlism/PageDock/releases) 下载；解压后将 App 放入「应用程序」目录。

每次构建使用 `v<版本号>+build.<构建编号>` 标签，指向触发构建的提交，不覆盖已经公开的 Release。仅当前主分支提交的构建会被标记为 Latest；失败时不公开 Release。拉取请求执行相同构建检查，但不创建 Release，也可以在 Actions 页面手动运行工作流。

流程只上传应用压缩包和校验文件，不上传测试配置、截图或日志。构建任务只有读取权限，发版任务单独使用 GitHub 提供的临时凭据；无需配置个人访问令牌。自动构建沿用本地签名，不包含 Apple Developer ID 签名或公证。

## 本地数据与隐私

默认数据目录为 `~/Library/Application Support/WebpageApp/`，其中保存页面网址、外观与插件设置，以及 Chromium 的 Cookie、缓存和本地存储。测试可通过绝对路径环境变量 `WEBPAGE_APP_DATA_DIR` 指定独立目录。

移除页面只删除列表条目，不清除站点登录数据。网页仍按站点自身的逻辑发起网络请求，账号操作由相应网站处理。

提交代码或分享文件前，不要包含应用数据目录、环境变量文件、私钥或带有账号信息的截图。仓库忽略本地依赖、构建产物、测试输出和常见敏感文件；打包时只包含运行所需源码。
